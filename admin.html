아직 통계 저장소가 연결되지 않았어요

랜딩페이지는 서버가 없어서 접속 기록을 남기려면 무료 데이터베이스인 Supabase가 필요합니다. 5분이면 끝납니다.

  1. supabase.com 에서 GitHub 계정으로 가입하고 새 프로젝트를 만듭니다. 리전은 Northeast Asia (Seoul)을 고릅니다.
  2. 프로젝트 화면 왼쪽 SQL Editor를 열고, 저장소의 supabase.sql 내용을 전부 붙여넣어 실행합니다.
  3. 왼쪽 Settings 메뉴에서 API로 들어가 Project URL과 anon public 키를 복사합니다.
  4. 저장소의 config.js에 두 값을 붙여넣고 저장한 뒤 커밋합니다.

저장이 반영되면 이 페이지가 자동으로 통계를 보여줍니다.

통계를 불러오지 못했어요

config.js의 주소와 키가 맞는지, supabase.sql이 실행됐는지 확인해 주세요.
